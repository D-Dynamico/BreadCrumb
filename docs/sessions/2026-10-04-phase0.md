## Changes

### 1. Doc review fixes (before any code)

A read-through before Phase 0 found six gaps. The user decided each one; the docs now
match. No code changed.

- **Duplicates were impossible in Admin** (D17). The "invoice number unique per vendor"
  rule would have turned the journal-off ablation into a validation error instead of a
  duplicate, so it measured the app, not the worker. Rule dropped; duplicates are
  counted across all effect types.
- **No approvable action outside family 4** (D18). Creating a payable was tier 1, so the
  only tier 2 action was in the stretch family, and Phase 4's approval exit criterion
  had nothing to approve. Now money commits above `APPROVAL_THRESHOLD_INR` are tier 2,
  and family 2's welcome email goes to an external personal address (tier 2). Demo
  scene 6 and the Phase 4 exit criterion were rewritten to match.
- **The idempotency key was overstated** (D19). The docs implied apps honored it. Now
  they say plainly that the natural-key check plus reconcile prevent duplicates. The
  Admin API accepts an `Idempotency-Key` header on writes; forms do not.
- **Logins would trip the network watch** (D20). Added a declared `login` action. All
  sandbox reads, including search and HTMX partials, are GET.
- **Windows** (D21). `uv` plus a Python task runner (`uv run tasks <name>`) instead of
  make. Crash points use `os._exit`; external kills use `breadcrumb kill <run_id>`,
  which needs the worker's process ID in the run record.
- **Small things** (D22). A real Phase 0 test; an append-only audit table in the
  sandbox for the oracle; deny-list built from the seed generator's whole name pools.

One detail I added while writing D18: which params count as "money" is decided from
the ledger fact type (`money`), not from field names, to keep the gateway generic.

### 2. Phase 0 scaffold

- **uv 0.12.22** installed with winget (`astral-sh.uv`). New shells pick it up from
  PATH; shells already open need a restart.
- **`pyproject.toml`** (hatchling build, Python pinned to 3.12 in `.python-version`)
  with two entry points: `breadcrumb` (Typer CLI) and `tasks` (`tasks.py`, an argparse
  runner with no extra dependencies). Versions are locked in `uv.lock`.
  - Runtime: fastapi, uvicorn, jinja2, python-multipart, httpx, pydantic,
    pydantic-settings, pyyaml, typer, playwright.
  - Dev: ruff, mypy (strict, Pydantic plugin), pytest, types-pyyaml.
  - Deliberately not yet: the model SDK (provider undecided, Phase 2) and PDF libraries
    (Phase 1).
- **Task runner.** `setup` runs `uv sync` and installs Playwright Chromium. `lint` runs
  ruff check, ruff format check, mypy and the generality check, runs all four even if
  one fails, and reports which failed. `test` runs pytest. `seed`, `sandbox`, `ui` and
  `eval` take their final arguments but exit with code 2 and name their phase, so a
  script can never mistake a stub for success. The CLI's `run`, `resume`, `runs` and
  `kill` behave the same way.
- **Generality check** (`scripts/check_generality.py`). Scans `breadcrumb/` and
  `prompts/` for three things: names from the seed name pools or task ids (whole-word,
  case-insensitive), imports of `sandbox` or `harness` (parsed with `ast`, so comments
  and strings don't trip it), and any mention of the oracle (`oracle`, `8109`,
  `ORACLE_URL`). Pools are read from `sandbox/seed/name_pools.json`, which Phase 1 must
  create (recorded in `SANDBOX.md`). Until then the deny-list is empty, which the check
  reports ("0 deny-listed names") rather than hiding.
- **Skeleton.** Every package in `ARCHITECTURE.md` exists with a one-line docstring
  naming its job and phase. `prompts/` and `harness/tasks/{dev,heldout}/` hold
  `.gitkeep` files.
- **`.env.example`** documents every key. Model keys are provider-neutral
  (`LLM_PROVIDER`, `LLM_MODEL`, `LLM_API_KEY`) because the user is weighing free
  providers (Gemini, Groq) against the Anthropic API named in the docs. `ORACLE_URL`
  sits in a "harness only" section.
- **`.gitignore`** anchors `/runs/` so it doesn't hide the `breadcrumb/runs/` package.
- **README.md** replaced. The committed one was only the title `# BreadCrumb`; the new
  stub says it's a work in progress and gives the three check commands. The full README
  is a Phase 7 task.
